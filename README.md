# KodiakX HOI4 Modding Studio

[🌐 웹사이트 열기](https://urz-studio.github.io/Hoi4-modding/)

## 한국어

국민중점, 이벤트, 결정 등 하츠 오브 아이언 IV(HOI4) 모드의 구조를 시각적으로 설계하기 위한 브라우저 기반 편집기 프로젝트입니다. 현재 공개 버전은 사용자 인터페이스를 소개하는 시연용 프로토타입이며, 프로젝트 저장과 실제 게임 파일 출력 기능은 개발 중입니다.

## English

A browser-based editor concept for visually planning Hearts of Iron IV (HOI4) mod content, including national focuses, events, and decisions. The current public version is a UI prototype; project saving and game file export are in development.

## 日本語

国家方針、イベント、ディシジョンなど、Hearts of Iron IV（HOI4）MODの構成を視覚的に設計するためのブラウザベース編集ツールです。現在公開中のバージョンはUIプロトタイプで、プロジェクトの保存とゲームファイルの出力機能は開発中です。

## 简体中文

这是一个基于浏览器的编辑器概念项目，用于可视化规划《钢铁雄心 IV》（HOI4）模组内容，包括国家路线、事件和决议。当前公开版本是界面演示原型，项目保存和游戏文件导出功能仍在开发中。
